## 1. 需求分析

### 1.1 项目背景

图（Graph）是计算机科学中最重要的非线性数据结构之一，广泛应用于社交网络分析、交通路线规划、网页链接分析、电路设计、任务调度等领域。图的遍历——即按照某种规则系统地访问图中所有顶点且每个顶点仅访问一次——是图算法的基础操作，几乎所有复杂的图算法（如最短路径、拓扑排序、连通分量、最小生成树等）都依赖于对图的遍历。

本项目旨在运用C语言和数据结构知识，设计并实现一个图遍历的完整演示系统。系统选择邻接表作为图的存储结构，分别使用栈和队列实现非递归的深度优先遍历（DFS）和广度优先遍历（BFS），并通过构建生成树和凹入表可视化输出，直观展示两种遍历方式的本质差异。通过本项目，可以深入理解DFS的后进先出（LIFO）回溯策略与BFS的先进先出（FIFO）逐层扩展策略，掌握显式栈和循环队列的应用技巧，以及生成树的构建与可视化方法。

## 2. 概要设计

### 2.1 数据结构设计

系统选择邻接表作为图的核心存储结构，基于以下设计考量：邻接表采用数组+链表混合结构，每个顶点的邻接关系通过单向链表存储，空间复杂度为O(V+E)，远优于邻接矩阵的O(V?)，尤其适合稀疏图的场景。对于无向图，每条物理边被拆分为两条有向边分别存储在两端顶点的链表中，保证了邻接关系的对称性和O(1)的邻接点查询效率。顶点编号采用1-based索引，下标0闲置，简化了用户交互逻辑。

遍历算法选择非递归实现，基于以下原因：(1) 递归DFS受限于系统调用栈深度（通常~1MB），对于大规模图可能导致栈溢出，非递归版本使用堆上的显式栈，容量更大且更可控；(2) 非递归实现便于单步调试和过程跟踪，更符合教学演示的需求；(3) 显式栈配合逆序入栈技巧，使非递归DFS的遍历顺序与递归版本完全一致。BFS使用循环队列而非普通数组队列，通过取模运算实现首尾相接，配合size字段无需牺牲空间即可区分队列的空/满状态，空间利用率为100%。

## 5. 总结

本次课程设计实现了一个功能完整的图遍历演示系统，完成了图的创建/管理（手动创建、文件读写、邻接表显示）、两种核心遍历算法的非递归实现（DFS使用显式栈、BFS使用循环队列），以及生成树的构建和凹入表可视化输出。系统代码组织清晰、注释详尽，采用了模块化设计思想，将栈/队列基础操作、图生命周期管理、遍历算法实现和可视化输出分离为独立的模块，模块间耦合度低、职责清晰。

在技术实现方面，通过本项目深入理解了DFS的回溯机制（随栈的push/pop自然实现）与BFS的逐层扩展机制（随队列的enqueue/dequeue自然实现）的本质差异。掌握了非递归算法的设计技巧：如何通过显式栈模拟递归过程中的回溯、如何通过逆序入栈保证非递归遍历顺序与递归版本一致、如何通过循环队列的取模运算高效管理FIFO逻辑。生成了DFS深而窄、BFS浅而宽的两种生成树，在可视化输出中直观对比了两种遍历策略对生成树结构的实质影响。通过本次实践，对图数据结构的存储、遍历和分析有了系统性的掌握。
