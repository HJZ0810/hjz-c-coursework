## 1. 需求分析

### 1.1 项目背景

在科学计算和工程应用中，多项式是最基本的数学对象之一。从信号处理中的滤波器设计到计算机图形学中的曲线拟合，多项式运算无处不在。然而，实际应用中的多项式往往是稀疏的——即大部分系数为零，只有少数几项具有非零系数。例如x^100+1只有2个非零项，但如果用数组按指数顺序存储则需要101个元素，浪费了99个存储位置。

本项目旨在运用C语言和数据结构知识，设计并实现一个高效的一元稀疏多项式计算器。该系统采用带头结点的单链表存储多项式，仅保存非零系数项，按指数降序排列，天然支持稀疏存储优化。系统实现了多项式的加法、减法、乘法、求值和求导等核心运算，其中加法采用有序链表归并算法、乘法采用逐项相乘加合并策略，充分体现了链表数据结构在有序归并运算中的优势。通过本项目，深入理解了单链表的插入合并操作、浮点数精度比较、以及稀疏数据存储优化的核心思想。

## 2. 概要设计

### 2.1 数据结构设计

系统选择带头结点的单链表作为多项式的存储结构，基于以下设计考量：多项式的非零项数量动态变化，链表可按需动态扩展；多项式运算涉及频繁的插入和删除操作（尤其是同类项合并），链表的插入/删除只需修改指针，无需像数组那样移动大量元素；稀疏多项式的核心特征是大量系数为零的项无需存储，链表结构天然支持这一特性——只存储非零项，跳过零系数项，节省大量内存空间。

链表按指数降序排列，这一设计决策带来三大优势：第一，加法和减法运算可以采用双指针归并算法，一次遍历即可完成，时间复杂度O(m+n)；第二，输出时天然按指数从高到低排列，符合数学书写习惯；第三，insertTerm()函数在插入新项时保持有序性，同时自动合并同类项、删除零系数项。头结点作为哨兵结点简化了边界判断——空链表和非空链表的操作逻辑统一，在链表头部插入时无需修改头指针。此外，支持负指数扩展了多项式的表达范围，使系统可以处理如3x^(-2)+2x^(-1)+1等有理函数形式的多项式。

## 3. 详细设计

### 3.1 核心数据结构

```c
/* ======================== 常量定义 ======================== */
#define MAX_POLYS       10      /* 程序最多同时管理的多项式数量 */
#define FILENAME_LEN    256     /* 文件名缓冲区长度 */
#define EPS             1e-9    /* 浮点数比较精度阈值 */

/* ======================== 自定义数学函数 ======================== */
static double my_fabs(double x)
{
    return x < 0.0 ? -x : x;
}

/* 快速幂算法：计算 x^n，O(log n) */
static double my_pow(double x, int n)
{
    if (n == 0) return 1.0;
    int neg = 0;
    if (n < 0) { neg = 1; n = -n; }
    double result = 1.0, base = x;
    while (n > 0) {
        if (n & 1) result *= base;
        base *= base;
        n >>= 1;
    }
    return neg ? 1.0 / result : result;
}

static int is_integer(double x)
{
    return my_fabs(x - (double)(long long)x) < EPS;
}
typedef struct PolyNode {
    double  coef;               /* 系数：项的数值因子 */
    int     exp;                /* 指数：x 的幂次 */
    struct PolyNode *next;      /* 后继指针：指向指数更小的下一项 */
} PolyNode, *Polynomial;

/* 链表组织规则：
 * 1. 带头结点单链表，头结点不存储有效数据
 * 2. 结点按 exp 降序排列
 * 3. 不存在 coef 为零的结点
 *
 * 存储：f(x) = 3x^5 + 2x^3 - x + 7
 * [HEAD] -> [3,5] -> [2,3] -> [-1,1] -> [7,0] -> NULL
 */
```

## 5. 总结

本次课程设计实现了一个功能完整的一元稀疏多项式计算器，完成了多项式加法、减法、乘法、求值和求导五大核心运算，以及键盘输入、文件读取、序列输出和数学表达式输出等I/O功能。系统代码组织清晰、注释详尽，采用了不可变运算的设计模式——所有运算都返回新多项式而不修改原始数据，避免了副作用，使同一个多项式可以安全地参与多次运算。

在技术实现方面，深入理解了带头结点单链表在有序归并运算中的应用，掌握了insertTerm()函数同时实现插入、合并和删除三种操作的精妙设计；通过自定义my_fabs()和my_pow()（快速幂算法）替代math.h库，提高了代码的跨平台可移植性；浮点数精度比较使用EPS阈值而非直接==比较，避免了浮点误差导致的逻辑错误。通过本次实践，对链表操作、内存管理和稀疏数据存储优化有了更深层次的理解。

### 改进方向

- **乘法效率O(m×n)**: 可用FFT加速到O(n·log n)
- **缺少除法运算**: 增加长除法算法实现完整四则运算
- **仅支持数值输入**: 增加解析数学表达式格式输入
- **频繁malloc/free**: 引入内存池减少系统调用
- **无LaTeX输出**: 增加LaTeX格式输出便于文档
