## 1. 需求分析

### 1.1 项目背景

随着物流运输行业的快速发展，运输公司对车辆信息管理的需求日益增长。传统的手工记录方式效率低下，容易出错，已无法满足现代化管理的需求。因此，开发一套 computerized 的车辆管理系统具有重要的现实意义。

本系统基于C99标准，采用单链表数据结构实现车辆信息的动态管理。系统不仅实现了基本的增删查改功能，还提供了分类统计、批量操作等高级功能。通过文本文件实现数据持久化，确保数据在程序重启后不丢失。系统设计遵循模块化原则，代码结构清晰，注释完整，适合作为数据结构与算法课程的实践项目。

## 2. 概要设计

### 2.1 数据结构设计

系统采用单链表作为核心数据结构存储车辆信息。选择链表而非数组的主要理由是：1）车辆数量不确定，链表可按需动态增长，无预分配浪费；2）插入/删除操作只需调整指针，无需移动大量元素；3）节点内存独立分配，无碎片化问题；4）符合课程设计对链表操作的练习要求

 TypeStat辅助结构用于分类统计功能。采用静态数组+去重计数的方式，避免引入哈希表等额外复杂度。驾驶员去重采用线性扫描drivers[]数组，时间复杂度O(d)，因规模较小（MAX_DRIVERS=50），无需更复杂的数据结构

## 3. 详细设计

### 3.1 核心数据结构

```c
typedef struct Vehicle {
    char  id[MAX_STR];       /**< 车辆编号（格式：V001, V002, ...） */
    char  plate[MAX_STR];    /**< 车牌号（如：京A-10001）         */
    char  type[MAX_STR];     /**< 车辆类型（如：重型卡车、冷藏车） */
    char  driver[MAX_STR];   /**< 驾驶员姓名                        */
    float mileage;           /**< 累积行驶里程（单位：万公里）      */
    float value;             /**< 资产价值（单位：万元）            */
    struct Vehicle *next;    /**< 指向链表下一个节点                */
} Vehicle;
typedef struct {
    char  type[MAX_STR];                /**< 类型名称                 */
    float total_mileage;                /**< 该类型累积里程总和       */
    float total_value;                  /**< 该类型资产价值总和      */
    int   vehicle_count;                /**< 该类型车辆数量          */
    int   driver_count;                 /**< 去重后驾驶员数量        */
    char  drivers[MAX_DRIVERS][MAX_STR]; /**< 驾驶员姓名列表（去重） */
    int   driver_num;                   /**< drivers[]实际使用长度   */
} TypeStat;
```

## 5. 总结

本车辆管理系统基于单链表数据结构，成功实现了车辆信息的全生命周期管理。系统采用模块化设计，代码结构清晰，注释完整详细（Doxygen风格），符合专业开发规范。通过使用单链表，系统能够高效处理动态数量的车辆信息管理需求，避免了固定数组的大小限制。

本项目的亮点包括：1）二级指针删除技巧，统一处理头节点和中间节点删除，代码简洁高效；2）安全的字符串处理，使用strncpy+手动补'\0'防止缓冲区溢出；3）容错设计，文件不存在时静默跳过，数据格式错误时跳过该行；4）测试数据初始化，首次运行自动创建15条测试数据。通过本项目的开发，深入理解了单链表的各种操作（创建、插入、删除、遍历），以及模块化程序设计方法。
