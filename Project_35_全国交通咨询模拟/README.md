## 1. 需求分析

### 1.1 项目背景

在全国范围内，旅客出行时需要面对复杂多样的交通选择——不同城市间有高铁、飞机等多种交通方式，且往往涉及中转换乘。如何为旅客提供最优的出行方案（最快到达或最省钱到达），是一个具有实际意义的问题。传统的手工查询方式效率低下，且难以综合考虑中转等候时间等因素，无法满足现代旅客对出行决策辅助的需求。

本项目旨在运用C语言和数据结构知识，设计并实现一个功能完善的全国交通咨询模拟系统。该系统基于邻接表数据结构建模交通网络，采用Dijkstra单源最短路径算法求解最优路线（支持时间优先和费用优先两种模式），提供城市、火车、飞机三类数据的完整管理功能，并实现数据持久化存储。系统特别考虑了中转等候时间的计算（跨天自动处理），使查询结果更贴近实际旅行体验。同时，系统提供了登录验证机制保障数据安全，以及完善的CRUD操作，全方位满足交通咨询管理的需求。

## 2. 概要设计

### 2.1 数据结构设计

系统选择邻接表（Adjacency List）作为核心数据结构，基于以下设计考量：交通网络是一个稀疏图（大多数城市之间没有直达路线），邻接表的空间复杂度为O(V+E)，远优于邻接矩阵的O(V?)；遍历某城市的所有出发路线时，只需扫描实际存在的边，效率更高；对于课程设计的规模（MAX_CITIES=64，MAX_EDGES=512），邻接表既能节省内存，又能提供高效的图操作。

边存储在静态数组edge_pool[]中，而非动态分配（malloc/free），原因是：简化内存管理，避免内存泄漏风险；静态数组访问速度更快，且可以通过指针算术快速获取边索引（e - edge_pool）；编译时确定大小，零运行时开销。

邻接表 vs 邻接矩阵的选型：本系统的核心操作是Dijkstra最短路径求解，需要频繁遍历某顶点的所有邻接边。若使用邻接矩阵，每次需要扫描整行（V个元素），而邻接表只需遍历实际存在的边（通常为O(E/V)个）。对于稀疏图（E << V?），邻接表的效率优势明显。

边存储池的静态分配策略：edge_pool[]是一个静态数组，所有边集中存储，通过next指针串联成链表。删除边时采用'末尾覆盖'策略（compact_edge函数）：将数组最后一个元素复制到被删位置，然后重新挂链，保持数组紧凑无空洞。这种策略使得删除操作能在O(1)时间内完成物理空间的回收。

## 3. 详细设计

### 3.1 核心数据结构

```c
/*--- 系统配置常量 ---*/
#define MAX_CITIES      64    /* 最大城市数量       */
#define MAX_NAME       32    /* 城市名称最大长度   */
#define MAX_EDGES      512   /* 最大交通路线数量   */
#define MAX_ROUTE_NUM  16    /* 车次号/航班号最大长度 */
#define MAX_TIME_STR   8     /* 时间字符串缓冲区   */
#define INF            999999999  /* 无穷大距离值   */
#define DATA_FILE      "traffic_data.txt"
#define TRAIN          1     /* 交通工具类型：火车 */
#define PLANE          2     /* 交通工具类型：飞机 */
typedef struct Edge {
    int     type;           /* 交通工具类型：TRAIN(1)或PLANE(2) */
    char    route_num[MAX_ROUTE_NUM];  /* 车次号或航班号 */
    int     from;           /* 出发城市索引               */
    int     to;             /* 到达城市索引               */
    char    dep_time[MAX_TIME_STR];    /* 出发时间 HH:MM */
    char    arr_time[MAX_TIME_STR];    /* 到达时间 HH:MM */
    int     duration;       /* 路程时间（分钟）           */
    int     cost;           /* 票价（元）                 */
    struct Edge *next;      /* 邻接表链表指针             */
} Edge;
```

## 5. 总结

本次课程设计实现了一个功能完整的全国交通咨询模拟系统，完成了城市、火车、飞机的完整CRUD操作，支持最快到达和最省钱到达两种最优路线查询，通过文件I/O实现了数据持久化存储。系统代码组织清晰、注释详尽，采用了模块化的设计思想，各模块职责单一、耦合度低。特别实现了Dijkstra算法的两种变体（时间模式/费用模式），并正确处理了中转等候时间和跨天场景，具有较强的实用价值。

在技术实现方面，深入理解了邻接表数据结构在实际图论算法中的应用，掌握了静态内存池的管理技巧，巩固了Dijkstra最短路径算法和路径回溯的相关知识。通过本次实践，对图建模、权重设计、指针操作、文件序列化有了更深层次的理解。边存储池的静态分配策略和末尾覆盖删除策略是本次设计的亮点，体现了对传统动态内存管理方案的优化思考。
