## 1. 需求分析

### 1.1 项目背景

中国移动河北省分公司计划为省内12所高校建设专用通信网络，需要在满足所有高校互联互通的前提下，使总建设成本最小化。该问题在图论中被建模为：在无向加权图中求解最小生成树（Minimum Spanning Tree, MST）。12所高校分布在天津、唐山、秦皇岛、保定、石家庄5座城市，各城市间及城市内的高校之间共有25条候选通信线路，每条线路有对应的建设成本（单位：万元）。

本项目旨在运用C语言和数据结构知识，设计并实现一个高校通信网络建设辅助决策系统。系统基于邻接矩阵存储图结构，使用Kruskal算法求解最小生成树，通过并查集数据结构高效判环。系统支持交互式修改线路成本后重新计算MST、按地理区域分组展示网络拓扑、ASCII文本图形化展示树形结构、数据文件持久化等功能，全面覆盖从数据管理、算法计算到结果可视化的完整流程。

## 2. 概要设计

### 2.1 数据结构设计

系统核心采用邻接矩阵存储无向加权图，选择依据为：(1) 本项目规模（12个顶点、25条边，稠密度约38%）下邻接矩阵空间开销可接受（12×12×4=576字节）；(2) 两点间是否有边的查询时间复杂度O(1)，适合交互式修改时需要频繁检查的处理；(3) 矩阵对称性天然表达无向图特性，矩阵上三角遍历即可获取全部边。辅助数据结构方面，Edge结构体封装Kruskal算法的边操作单元，并查集parent[]数组支持高效连通分量管理。

并查集（Union-Find）是Kruskal算法高效判环的关键。本系统采用数组实现parent[]，findRoot()实现了路径压缩优化（隔代挂载parent[x]=parent[parent[x]]），使查找操作的摊还时间复杂度降至O(α(n))（α为反阿克曼函数，实际中近似常数）。unionSet()将两个根节点合并，返回1表示合并成功（边加入MST），返回0表示已在同一连通分量（跳过以避免成环）。这种设计将MST选边阶段的判环操作从朴素O(V)降至近似O(1)。

## 5. 总结

本次课程设计实现了一个功能完整的高校专用通信网络建设辅助决策系统。系统基于邻接矩阵存储图结构，使用Kruskal贪心算法结合并查集高效求解最小生成树，成功从25条候选线路中选出11条构成总成本149万元的最优通信网络方案。系统支持交互式数据修改、多维度MST展示（文本分组+ASCII图形）、文件持久化等完整功能。代码组织清晰、注释详尽，采用模块化设计思想，模块职责单一且耦合度低。

在技术实现方面，深入理解了图论中最小生成树问题的建模方法，掌握了Kruskal算法从理论到C语言实现的完整过程，巩固了并查集数据结构及其路径压缩优化技巧。通过UTF-8终端显示宽度的处理，加深了对字符编码底层机制的理解。文件I/O和标准输入缓冲区的处理也积累了宝贵的工程实践经验。

### 改进方向

- **密码硬编码明文**: 使用哈希存储，增加多用户
- **冒泡排序效率**: 替换为qsort()或堆排序
- **并查集无按秩合并**: 增加union by rank优化
- **仅Kruskal一种算法**: 增加Prim算法对比
- **终端UI简单**: 增加彩色和Graphviz导出
- **文本文件格式**: 改用JSON或CSV批量导入
