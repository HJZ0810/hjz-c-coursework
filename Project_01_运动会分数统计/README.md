## 1. 需求分析

### 1.1 项目背景

在各级学校运动会中，参赛学校众多、比赛项目繁杂、计分规则多样，传统的人工计分方式不仅效率低下、容易出错，而且在总分统计和排名输出环节需要反复核算，耗时耗力。随着学校数量的增加和比赛项目的多样化，手工管理方式已无法满足现代运动会对快速、准确、规范计分的需求。特别是在需要综合排序和按性别分类统计的场景下，人工操作极易产生遗漏和错误。

本项目旨在运用C语言和数据结构知识，设计并实现一个功能完善的运动会分数统计系统。该系统基于静态数组数据结构，支持学校信息管理、比赛项目配置、成绩录入与自动计分、多维度排序输出、按学校和项目查询以及二进制文件持久化存储等功能。系统提供TOP3和TOP5两种计分规则，覆盖男子和女子两类比赛项目，能够满足中小规模运动会的完整计分管理需求。

## 2. 概要设计

### 2.1 数据结构设计

系统选择静态数组作为核心数据存储结构，基于以下设计考量：运动会参赛学校和比赛项目的数量在赛前即可确定，数据规模通常在几十所学校和几十个项目的量级内，使用固定容量（MAX_SCHOOLS=50、MAX_PROJECTS=30、MAX_RESULTS=500）的静态数组完全满足需求。静态数组实现简单，无需动态内存管理，文件读写方便（直接fwrite整个数组），随机访问高效（O(1)按下标访问）。这种设计避免了动态链表或realloc方案的复杂性，符合课程设计规模的使用场景。三个全局数组（schools[]、projects[]、results[]）分别存储三类数据，通过id字段进行跨数组关联，实现了简洁的关系模型。

计分系统采用静态查找表（lookup table）实现O(1)分值查询，top5_scores[] = {0,7,5,3,2,1}和top3_scores[] = {0,5,3,2}直接以名次rank为下标索引取值，避免switch-case或if-else链的冗余代码。文件持久化采用二进制格式的「计数头+原始数据块」方案，先写入三个int计数器，再依次写入各数组有效部分，读写仅需一次fwrite/fread调用，格式紧凑高效。加载时采用「保存旧状态-读取-校验-失败回滚」的容错策略，任何步骤失败都会恢复到加载前的数据状态，保证异常情况下的数据安全。

## 3. 详细设计

### 3.1 核心数据结构

```c
/*--- 容量限制宏 ---*/
#define MAX_SCHOOLS     50      /* 最大学校数量         */
#define MAX_PROJECTS    30      /* 最大项目数量         */
#define MAX_RESULTS     500     /* 最大成绩记录数       */
#define MAX_NAME        64      /* 名称最大字符长度     */
#define FILENAME        "data.dat"  /* 持久化文件路径 */

/*--- 枚举：项目类别 ---*/
typedef enum {
    MALE = 0,       /* 男子项目 */
    FEMALE = 1      /* 女子项目 */
} ProjectCategory;

/*--- 枚举：计分规则 ---*/
typedef enum {
    TOP3 = 3,       /* 取前三名：分值 5,3,2   */
    TOP5 = 5        /* 取前五名：分值 7,5,3,2,1 */
} ScoringRule;
typedef struct {
    int id;                     /* 学校编号（1~n）   */
    char name[MAX_NAME];        /* 学校名称           */
    int total_score;            /* 总分               */
    int male_score;             /* 男子团体总分       */
    int female_score;           /* 女子团体总分       */
} School;
```

## 5. 总结

本次课程设计实现了一个功能完整的运动会分数统计系统，完成了学校信息管理、比赛项目配置、成绩录入与自动计分、多维排序输出、按学校和项目查询以及二进制文件持久化存储等全部功能。系统代码组织清晰、注释详尽（总计约800行，含大量Doxygen风格注释），采用模块化设计思想，划分为菜单界面、计分计算、数据管理、查找辅助、文件持久化、分数重算、业务功能和内置测试八个模块，各模块职责单一、耦合度低。

在技术实现方面，深入理解了静态数组数据结构在实际业务中的应用，掌握了枚举类型（ProjectCategory/ScoringRule）的设计和使用方法，巩固了二进制文件读写（fwrite/fread）和结构体序列化的相关知识。计分系统采用的静态查找表技术展示了以空间换时间的经典优化策略，增量更新与全量重算相结合的双机制确保了数据一致性。通过本次实践，对C语言结构体设计、函数职责划分、错误处理策略和防御性编程有了更深层次的理解。

### 改进方向

- **静态数组固定容量**: 改用realloc动态数组或链表支持弹性扩容
- **二进制格式不跨平台**: 改用JSON或CSV等文本格式提升兼容性
- **未实现删除操作**: 添加软删除标志或数组标记删除
- **选择排序O(n?)**: 可改用qsort()标准库快排
- **纯文本终端界面**: 增加颜色输出和交互引导
